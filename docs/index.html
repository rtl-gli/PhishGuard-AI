What it does

A practical project with a human purpose.

Phishing affects people every day. This project explores how an explainable machine-learning model can turn technical URL signals into guidance that anyone can understand.

01

Analyse a URL

Extracts 16 characteristics from a link, including length, domain structure, HTTPS, redirects, and suspicious symbols.

02

Explain the result

Shows the decision path behind the prediction instead of presenting an unexplained black-box score.

03

Help people act

Gives calm, practical next steps and safety guidance without asking for passwords or personal information.

How it works

From link to clearer decision.

01

Feature extraction

The URL is inspected without opening the website.

02

Decision tree model

A trained classifier estimates the likelihood of phishing.

03

Plain-language output

Signals, risk level, and next steps are shown together.

Model evaluation

Measured, not just promised.

The deployed decision tree was selected after comparing models and testing different tree depths on a balanced dataset.
